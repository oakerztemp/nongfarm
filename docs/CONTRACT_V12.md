## 2. ระบบจดหมาย + น้อง Limited ผู้เล่นใหม่
- `state.mail: [{ id, at, read, claimed }]` (≤ 20) ข้อความ/ของขวัญอ่านจาก `js/data/mail.js` ตาม id; id ที่ไม่รู้จักถูกทิ้ง
- `state.mailSent: [id]` จดหมายระบบที่ส่งแล้ว — `ensureMail` ส่งจดหมายที่ยังไม่เคยส่ง ใช้ทั้งเซฟใหม่และเซฟเก่า (ผู้เล่นเดิมก็ได้รับครั้งเดียว)
- จดหมายแรก `welcome_celestial`: ของขวัญ = **ยูนิคอร์นดาราจักร** (Limited)
  - สายพันธุ์ unicorn (ตำนาน) ไชนี่ สเตจวัยรุ่น นิสัยร่าเริง ชื่อ "ดาราจักร" `pet.limited = 'celestial'`
  - สีขนกาแล็กซี (palette เฉพาะ) + ออร่าสีรุ้งไล่เฉด + ดาวระยิบ + ประกายลอย — ได้จากที่นี่ที่เดียว
  - ส่งไปบ้านใหม่ไม่ได้ (กันหายและกันปั๊มผงดาว)
  - **ไม่ให้ของขวัญในลาน** (ทั้งเหรียญและของ): ตัวจำลองพบว่าตำนานเพิ่ม 1 ตัวตั้งแต่นาทีแรกทำให้ลานให้ของเป็น 43% (เหรียญ) / 30% (ของ mystic) ของรายได้วันแรก เกินกฎ 20% — ช่วยงานไร่ได้เต็มพลังตามปกติ
  - รับได้เมื่อลานหรือเปลอนุบาลมีที่ว่าง (ลานเต็ม → เข้าเปล)
- UI: ปุ่ม 📬 บนแถบหัว มีจุดแดงนับจดหมายที่ยังไม่อ่าน/ยังไม่รับ; modal รายการจดหมาย + ปุ่ม "🎁 รับของขวัญ"; การ์ดน้อง Limited มีกรอบรุ้ง + ป้าย "🌌 Limited"
- เกณฑ์ตัวจำลองเศรษฐกิจ (ใหม่): บอทที่รับของขวัญตั้งแต่วันแรก เทียบกับไม่รับ
  - รายได้วันที่ 14 ≤ 1.10 เท่า และ ≤ 4,500/ชม.
  - ลานให้ของ ≤ 20% ทุกวัน, เวลาถึงลาน M/L/XL อยู่ใน ±25% ของค่าฐาน V6
- เกณฑ์ผ่าน: test claim (ลานว่าง/ลานเต็ม→เปล/เต็มหมด→ไม่ให้รับ/รับซ้ำไม่ได้), ensureMail ไม่ซ้ำ, sanitise, rehome ถูกปฏิเสธ

## 3. รดน้ำทั้งหมด
- `waterAll(state)` ใน farm.js รดทุกแปลงที่ปลูกอยู่ ยังไม่โต และยังไม่รด; ปุ่ม "💧 รดน้ำทั้งหมด (n)" ในแถบเครื่องมือไร่เมื่อ n > 0

- เกณฑ์ผ่าน: test waterAll
