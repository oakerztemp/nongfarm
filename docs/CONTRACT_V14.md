# CONTRACT V14 — สูตรชิบิกับน้องทุกตัว + ไข่ตำนานของขวัญ

> 2026-10-26 · state ยังเป็น v9 (ไม่ bump)

## 1. สูตรชิบิกับน้องทุกตัว
- `js/data/models.js` ท้ายไฟล์: `chibify(spec)` ใช้กับทุก spec ยกเว้นที่ปรับมือแล้ว (`CHIBI_TUNED`)
  - ตา × 1.25 (ไม่เกิน 0.21) และสูงอย่างน้อย 1.3 เท่า → ตาโตมีประกาย
  - หัว × 1.06
  - ปาก muzzle / pointy สั้นลง × 0.8, จะงอยปาก beak × 0.85
  - แก้มแดงคงตามที่แต่ละ spec ตั้งไว้
- ปรับมือ (สัดส่วนแบบยูนิคอร์น ขาสั้นอวบ หัวใหญ่): ม้า ลามะ กวาง (ขายาวทั้งสามตัว)
- เกณฑ์ผ่าน: ทุกตัวอยู่ในงบสามเหลี่ยมเดิม (ทุ่งนา 1500 / ตำนาน 1800); ตรวจด้วยตาใน tests/models.html ทุกถิ่น

## 2. ไข่ตำนานของขวัญ
- จดหมาย `gift_legend_egg` มาถึงเมื่อถึง **Lv.5** (`minLevel`; `ensureMail` ถูกเรียกตอนเลเวลอัพ) ผู้เล่นที่ Lv.5 ขึ้นไปอยู่แล้วได้ทันที
  - ไม่ส่งวันแรก: รายได้วันแรกน้อยมาก ตำนานเพิ่มอีกตัวจะทำให้ลานให้ของเกิน 20% (เหมือนที่เจอใน V12)
- `LEGEND_EGG` (`egg_legend`, ฟัก 10 นาที) ไม่อยู่ใน `EGGS` → ไม่มีขาย ไม่มีขายคืน ไม่ดรอป; รับแล้วเข้าตู้ฟักทันที (ตู้เต็ม = รับไม่ได้ จดหมายยังรออยู่)
- ฟักได้น้องตำนาน 1 ตัว สุ่มเท่ากันทุกชนิด เป็นน้องปกติ (ให้ของในลาน ส่งไปบ้านใหม่ได้)
- เกณฑ์ตัวจำลองเศรษฐกิจ: บอทรับทั้งยูนิคอร์น (นาทีแรก) และไข่ (ทันทีที่ถึง Lv.5) → รายได้วันที่ 14 ≤ 1.10 เท่า และ ≤ 4,500/ชม., ลาน ≤ 20% ทุกวัน, เวลาถึงลาน M/L/XL ±25%
