## 1. ครัว (หัวหน้า)
- `js/data/recipes.js`: 9 เมนู ทำจากผลผลิตไร่ + ของป่า (+ นม/เนื้อจากร้าน) ปลดล็อกตามเลเวล
  - สลัดผักรวม (Lv1) · ซุปมะเขือเทศ (Lv2) · ข้าวต้มปลา (Lv2) · สตูว์เนื้อ (Lv3) · สลัดใบเขียว (Lv3) · สมูทตี้เบอร์รี่ (Lv4) · พายฟักทอง (Lv6) · ปาร์ตี้ผลไม้ (Lv7) · ขนมธัญพืช (Lv8)
- เมนู = ไอเทม `type: 'dish'`, **ซื้อไม่ได้ ขายไม่ได้** (`buy/sell: null`), มี `food` (hunger/happy/tags) ป้อนผ่าน `feedPet` เดิม → ขึ้นในถาดอาหาร 3D และตัวเลือกอาหารเอง
- `cook(state, recipeId)` ใน `js/kitchen.js`: เช็คเลเวล + วัตถุดิบ → หักวัตถุดิบ → ได้เมนู 1 จาน (ทันที)
- ป้อนเมนู (เพิ่มจาก feedPet ปกติ):
  - **หัวใจเท่าอาหารปกติ** (2, ของโปรด 5) — ไม่เพิ่มเกินของเดิม เพราะหัวใจมีผลกับพลังงานไร่/ของขวัญลาน
  - `pet.treat = { id, until: now + 3 ชม. }` สถานะ "😋 อิ่มอร่อย" **มีผลแค่ภาพ** (ไม่แตะค่าใดๆ ที่มีผลกับรายได้)
  - เมนูโปรดของแต่ละสายพันธุ์ (`favoriteDish(species)` คำนวณจากอาหารที่กินได้ ไม่สุ่ม) → ครั้งแรกที่ได้กิน: `pet.favDishKnown = true` + บันทึกไดอารี่ + ฉลองในลาน
- เกณฑ์ผ่าน: test cook/feed/treat/favourite/sanitise

## 2. ความน่ารักในลาน 3D (หัวหน้า)
- แก้บั๊กเดิมระหว่างทาง: ฉากน้องๆ ทักทายจบเองหลัง 7 วิ แล้ว `stepGreet` อ่าน `greet` ที่ถูกล้างไปแล้ว → ลาน 3D พังกลับเป็นรายการ
- ระหว่างอิ่มอร่อย: กลีบหัวใจสีชมพูลอยรอบตัว + ฟองคำพูด 😋 เป็นระยะ + กระโดดดีใจเป็นพักๆ
- ได้กินเมนูโปรด: confetti + ประกาย + ฟอง 💕
- การ์ด/รายละเอียดน้อง: ป้าย "😋 อิ่มอร่อย" และ "🍽️ เมนูโปรด: ??? / ชื่อเมนู"
- ปุ่ม 🍳 ครัว ที่หัวลาน (ทั้งโหมด 3D และรายการ) → หน้าต่างสูตร: วัตถุดิบที่มี/ต้องใช้, ปุ่ม "ทำ"

## 3. เกณฑ์เศรษฐกิจ (ไม่แตะรายได้)
- เมนูขายไม่ได้ ซื้อไม่ได้ ไม่ให้เหรียญ/ผงดาว/หัวใจเกินอาหารปกติ และไม่อยู่ในของขวัญรายวันจากน้อง (reviewer พบว่า pool ของขวัญเดิมกรองด้วย `sell <= 60` ซึ่ง `sell: null` หลุดเข้าไป → เมนูฟรีไม่ต้องใช้วัตถุดิบ; แก้แล้ว + test)
- ทุกเมนู: `hunger ≤ 2 × มูลค่าขายวัตถุดิบรวม` (อาหารเม็ดให้ 2 หิว/เหรียญ) → ทำอาหารแทนซื้อไม่ประหยัดกว่า
- ทุกเมนู: `happy` เท่าอาหารธรรมดา (≤ 6 เท่านม) — ความสุขคือรายได้: น้องที่สุข ≥ 70 ให้ของขวัญลานเต็มอัตรา ตัวจำลองพบว่าเมนูสุข +25 ทำรายได้ลานวันแรก 13 vs 10/ชม. และแม้ +8 ก็ทำให้ลานวันแรกของ seed 7 เป็น 21.9% (ไม่ทำอาหาร 13.2%) → ตัดสุขออก ความน่ารักอยู่ที่ภาพ/ท่าทาง/เมนูโปรดอย่างเดียว
- ตัวจำลอง (เฉลี่ย 4 seed เหมือนเกณฑ์ V11): บอทที่ทำ+ป้อนเมนูวันละ 1 จาน (ทำทันทีหลังเก็บเกี่ยว) vs ไม่ทำ → รายได้ ≤ +3%, รายได้จากลาน ≤ +5% (ค่าเฉลี่ย), ลาน ≤ 20% ทุกวันบน seed มาตรฐาน (เหมือนเกณฑ์ทุกรอบที่ผ่านมา; seed อื่นวันแรกมีน้อง 1–2 ตัว แกว่งตามน้องที่ฟัก), วันที่ 14 ≤ 4,500/ชม., เวลาถึงลาน M/L/XL ±25% ของค่าเฉลี่ยตอนไม่ทำอาหาร และไม่เร็วกว่าค่าฐาน V6 (ทำอาหารช้าลงได้: บอท realistic ถึงลาน M ช้ากว่าฐาน ~3 ชม. เพราะผลผลิตรอบแรกลงหม้อ)
  - วัตถุดิบที่เอาไปทำอาหารนับเป็นรายได้ที่มูลค่าขาย (ผู้เล่นเลือกไม่ขาย) ไม่อย่างนั้นวันแรกที่รายได้เหรียญน้อย สัดส่วนลานจะดูสูงเกินจริง
  - เทียบ seed เดียว/รายวันไม่ได้: เปลี่ยนการกระทำนิดเดียว ลำดับสุ่มเปลี่ยนทั้งรอบ ตัวเลขแกว่งหลาย % เอง
