# CONTRACT V18 — เล่นกับน้องแบบจริงจัง (ซูมเข้าหาน้อง) + น้อยใจ/ป่วยง่าย + ของเล่นแทน

> 2026-10-27 · ผู้ใช้สั่ง (deploy ได้เลยเมื่อเสร็จ ไม่ต้องถาม) · state ยังเป็น v9

## โจทย์จากผู้ใช้
1. เล่นกับน้องแต่ละตัวให้จริงจังขึ้น: ถ้าไม่อยากเสียเวลาเล่น ต้องซื้อของเล่นให้น้องเล่นแทน ไม่อย่างนั้นน้องจะน้อยใจ จนถึงป่วยง่าย
2. กดเล่นแล้วกล้อง **ซูมเข้าไปหาน้อง** เห็นน้องชัดๆ เจาะเล่นทีละตัว (ผู้เล่นบอกว่าน้องอยู่ในลานไกลๆ ซูมดูชัดๆ ไม่ได้)

## 1. ความคิดถึง / น้อยใจ (logic, js/pets.js)
- `pet.playedAt` (ms) = ครั้งล่าสุดที่ได้เล่นจริงหรือได้ของเล่น · เซฟเก่า/น้องใหม่ = ตอนโหลด/ตอนเกิด (ไม่มีใครน้อยใจทันทีหลังอัปเดต) · รับจากเปลเข้าลาน = เริ่มนับใหม่
- เวลาที่น้องไปทำงาน/ออกสำรวจไม่นับ (นาฬิกาเดินเฉพาะตอนอยู่บ้าน): ตัวจำลองพบว่าน้องที่ประจำแปลงแทบไม่เคยว่างให้เล่น เลยน้อยใจและป่วยทั้งที่เป็นตัวทำเงิน
- `lonelyLevel(pet)`: 0 ปกติ (< 24 ชม.) · 1 **คิดถึง 🥺** (24–48 ชม.) · 2 **น้อยใจ 😢** (≥ 48 ชม.) · น้องในเปลอนุบาล = 0
- ผล: ความสุขลดเร็วขึ้น ×1.25 / ×1.5 · ระดับ 2: ป่วยจากหิว/สกปรกเร็วขึ้น (1 ชม. แทน 2 ชม.) และ **ป่วยใจ** ถ้าสุข ≤ 10 ติดต่อกัน 3 ชม.
- รีเซ็ตความคิดถึง: เล่นจริง (โหมดซูม) หรือให้ของเล่น (`care_toy` 40 เหรียญ) — ลูบ/ป้อนอาหารไม่นับ
- ปุ่ม "เล่น" แบบกดทีเดียวจบหายไป: เล่น = เข้าโหมดซูมเล่นจริง (~20 วิ); อยากประหยัดเวลา = ให้ของเล่น

## 2. โหมดเล่นซูม (3D, js/ui/barn3d.js + engine + js/ui/playGame.js)
- engine: `world.setCloseUp({ pos, look })` / `clearCloseUp()` กล้องค่อยๆ ลอยเข้าไปใกล้ (นอกกรอบ zoom/pitch ปกติ) แล้วกลับที่เดิม
- เข้าโหมด: น้องหันหน้าหากล้อง กล้องซูมระดับสายตาน้อง ซ่อน UI ลาน ปุ่ม/ถาดอื่นหาย
- มินิเกม 20 วิ: ของเล่น (🎾 🪶 🧶 🫧 ⭐) โผล่รอบตัวน้อง แตะให้ทันก่อนหาย → น้องกระโดด/หมุน/ดีใจ หัวใจลอย คอมโบ · ลูบน้องได้ระหว่างเล่น · ปุ่ม ✕ ออกก่อนได้
- จบ: `playSession(state, petId, score)` สุข +20 (+2/แต้ม ไม่เกิน +20) หัวใจ +3 (+1 ต่อ 5 แต้ม ไม่เกิน +2 ภายใต้เพดานรายวันเดิม 30) รีเซ็ตความคิดถึง
- โหมดรายการ (ไม่ใช่ 3D): ปุ่มเล่นเปิดหน้าต่างมินิเกมเดียวกัน กับน้องตัวใหญ่ (อีโมจิเด้ง)
- ใช้ได้บนมือถือ (แตะ) และเดสก์ท็อป (คลิก)

## 3. การแสดงผล
- การ์ด/รายละเอียดน้อง: "🥺 คิดถึงเรา" / "😢 น้อยใจ" + บอกวิธีแก้ (เล่นด้วย หรือให้ของเล่น)
- ลาน 3D: น้องที่คิดถึง/น้อยใจ มีฟอง 🥺/😢 เป็นระยะ

## 4. เกณฑ์ตัวจำลองเศรษฐกิจ
- บอทปกติ (เล่นเมื่อสุข < 50 หรือเมื่อคิดถึง): เกณฑ์เดิมทั้งหมดผ่าน (รายได้วันที่ 14, ลาน ≤ 20%, ลาน M/L/XL ±25%)
- บอทไม่เล่นเลย: ป่วยบ่อยกว่าบอทปกติชัดเจน (บทลงโทษทำงานจริง) แต่ไม่ crash
- บอทให้ของเล่นแทนการเล่น: ไม่ป่วยเพราะน้อยใจ รายได้ไม่หายเกิน 10% เทียบบอทปกติ (ของเล่นเป็นค่าใช้จ่ายที่จ่ายไหว)
- การเล่นจริงให้หัวใจเพิ่มได้ภายใต้เพดานรายวันเดิมเท่านั้น
