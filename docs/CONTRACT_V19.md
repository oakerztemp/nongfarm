## 1. เลือกจำนวนขาย (กระเป๋า, js/ui/farmView.js)
- ไอเทมที่มี > 1 ชิ้น: แถว `[−] [ช่องจำนวน] [+]` + ปุ่ม `ขาย xN +ราคา🪙` + ปุ่มลัด `ทั้งหมด`
- กด −/+ ทีละ 1 (กดค้างไม่ต้อง) · พิมพ์ตัวเลขเองได้ · ค่าถูกจำกัด 1..จำนวนที่มี · ราคาบนปุ่มอัปเดตทันที
- จำนวนที่เลือกจำไว้ต่อไอเทม (ไม่หายตอนหน้าจอรีเฟรชทุกวินาที) · ขายแล้วกลับเป็น 1 · มี 1 ชิ้น = ปุ่ม `ขาย +ราคา` ปุ่มเดียว
- logic `sellItem` เดิม (ตรวจจำนวนอยู่แล้ว)

## 2. มินิเกม "น้องอยากได้อะไร" (js/ui/playGame.js + barn3d.js + petsView.js)
- เหนือหัวน้องมี **ฟองความคิด** บอกของเล่นที่น้องอยากได้ตอนนี้ (เปลี่ยนทุก ~4 วิ)
- ของเล่นโผล่รอบตัวน้องเหมือนเดิม ประมาณครึ่งหนึ่งเป็นชิ้นที่น้องอยากได้
- แตะ **ถูกชิ้น**: +1 แต้ม คอมโบ · น้องดีใจ (ตายิ้มหยี ^^ กระโดด 😍/🥰)
- แตะ **ผิดชิ้น**: −1 แต้ม (ไม่ต่ำกว่า 0) คอมโบหาย · น้อง **ร้องไห้** (ก้มหน้า สั่น น้ำตา 💧 + 😭)
- ชิ้นที่อยากได้หายไปโดยไม่ได้แตะ: คอมโบหาย น้องทำหน้า 🥺 เบาๆ (ไม่ลบแต้ม)
- **ของเล่นชิ้นโปรด** (ไอเดียเสริม): น้องแต่ละตัวมีของเล่นโปรด 1 ชิ้น (สุ่มคงที่ตาม id) อยากได้บ่อยกว่าชิ้นอื่น · แตะถูกตอนน้องอยากได้ชิ้นโปรด = +2 แต้ม ❤️ · ครั้งแรกที่ทำได้ → "ค้นพบแล้ว! ของเล่นโปรดของน้องคือ 🧶" บันทึก `pet.favToyKnown` + ไดอารี่ · ก่อนค้นพบแสดง "???" ในหน้ารายละเอียดน้อง
- รางวัล/เพดานเดิม (`playSession` คะแนน 0–10) · ออกก่อน 8 วิไม่นับ (เดิม)
- โหมดรายการ: อีโมจิน้องตัวใหญ่ + ฟองความคิด · ถูก = เด้ง+😍 · ผิด = สั่น+😭+น้ำตา

## 3. state / logic (js/pets.js, js/state.js)
- `PLAY_TOYS` (7 ชิ้นเดิม) · `favToyOf(pet)` = ชิ้นโปรดคงที่ตาม `hashId(pet.id)`
- `playSession(state, petId, score, { favFound })`: `favFound` = แตะชิ้นโปรดถูกอย่างน้อยหนึ่งครั้ง → `favToyKnown = true` + journal `favToy` (ครั้งแรกเท่านั้น) · คืน `favNew`
- `favToyKnown` boolean (default false, sanitise)
