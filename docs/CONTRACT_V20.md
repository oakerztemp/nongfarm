# CONTRACT V20 — แสง สี ท้องฟ้า (Phase 5 รอบที่ 1)

> 2026-10-27 · ผู้ใช้อนุมัติแผน Phase 5 · ส่งภาพก่อน/หลังให้ดูก่อน deploy · ไม่แตะ state / เศรษฐกิจ

## สิ่งที่พบตอนถ่ายภาพ "ก่อน" (docs/design/v20/before_*.png)
- มุมกล้องปกติมองลงจากด้านบน จึงแทบไม่เห็นท้องฟ้า (เห็นในโหมดเล่นแบบซูมกับโหมดถ่ายรูป) → ความสวยรอบนี้ต้องมาจาก **แสงทั้งฉาก หมอกระยะไกล เงา และเอฟเฟกต์กลางคืน** มากกว่าท้องฟ้าอย่างเดียว
- "กลางคืน" ตอนนี้ = ธีมมืดของเครื่อง ซึ่งแค่หรี่ลงนิดเดียว แทบไม่ต่างจากกลางวัน

## 1. วงจรเวลาตามนาฬิกาจริง (js/world3d/daylight.js ใหม่, pure + test)
- `skyAt(hour)`: hour 0–24 (ทศนิยม) → { skyTop, skyBottom, fog, sun: { color, intensity, dir }, hemi: { sky, ground, intensity }, night 0..1, warm 0..1 }
- ช่วงเวลา (ไล่สีนุ่มระหว่างจุด): กลางคืน → **รุ่งสาง** 05:30–07:00 (ชมพูพีช) → **กลางวัน** → **เย็นสีทอง** 16:30–18:00 → **โพล้เพล้** 18:00–19:00 (ม่วงส้ม) → **กลางคืน** (แสงจันทร์ฟ้าอ่อน ยังเห็นน้องชัด)
- `isNightHour(h)` ใช้ร่วมกันทั้ง engine และ barn3d (โคม/ไฟเทศกาลติดตามช่วงเดียวกัน)
- ตั้งค่า "ช่วงเวลาในฉาก 3D": **🕒 ตามเวลาจริง** (ค่าเริ่มต้น) / **🌗 ตามธีมเครื่อง** (แบบเดิม: สว่างตอนธีมสว่าง กลางคืนตอนธีมมืด) · เก็บในเครื่อง (prefs)
- สภาพอากาศเดิม (เมฆ/ฝน) ยังทำงาน: ทำให้สีเทาลงทับช่วงเวลา · `fx.dimScene` เดิมยังใช้ได้

## 2. สีทั้งฉาก (engine)
- ปรับพาเลตต์แสง: กลางวันอุ่นและสดขึ้น · tone mapping ถ้าทดสอบแล้วสวยกว่าและไม่ทำให้สีน้องซีด (เลือกจากภาพเทียบ)
- **หมอกระยะไกล (fog)** สีตามท้องฟ้าช่วงนั้น: ต้นไม้/ทุ่งไกลๆ จางเข้าหาท้องฟ้า ให้ฉากมีมิติ (เย็นเป็นหมอกทอง กลางคืนหมอกน้ำเงิน)

## 3. ท้องฟ้า (engine)
- สีท้องฟ้า CSS เดิมเปลี่ยนตามเวลา (ภาพถ่ายในอัลบั้มก็ได้สีนี้)
- เมฆโลว์โพลีลอยช้าๆ รอบขอบฟ้า (1 draw call) สีตามเวลา (ขาว → ชมพูทอง → น้ำเงินเข้ม)
- **ดาว** กลางคืน (1 draw call) · เห็นในมุมซูม/ถ่ายรูป
- **เงาเมฆ** ลอยผ่านลานช้าๆ ตอนกลางวัน (1 draw call, ระดับ medium ขึ้นไป) ชัดขึ้นตอนเมฆมาก

## 4. กลางคืน
- **หิ่งห้อย** ลอยวนในลาน (1 draw call; high 28 ตัว / medium 14 / low ไม่มี)
- โคมในลานมีแสงเรือง (halo) ตอนกลางคืน

## 5. เงาจริงจากดวงอาทิตย์ (เฉพาะระดับกราฟิก high)
- shadow map เดียว (1024, PCF soft) ครอบเฉพาะลาน · น้อง บ้าน ของตกแต่ง ทอดเงาลงพื้น · ทิศเงาตามดวงอาทิตย์/ดวงจันทร์
- medium/low ใช้เงากลมเดิม · high ยังมีเงากลมจางๆ ใต้ตัวให้ดูติดพื้น
- ระบบลดระดับกราฟิกอัตโนมัติเดิมยังทำงาน: ถ้าลดจาก high จะปิดเงาจริง
