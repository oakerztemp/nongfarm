# CONTRACT V21 — ตัวน้องสวยขึ้น (Phase 5 รอบที่ 2)

> 2026-10-27 · ผู้ใช้สั่งเริ่ม V21 · ส่งภาพก่อน/หลังก่อน deploy · ไม่แตะ state / เศรษฐกิจ · ไม่เพิ่ม draw call ต่อตัว (งบเดิม 6 / 7)

## สิ่งที่พบจากภาพ "ก่อน" (docs/design/v21/before_*.png, แสงเที่ยง V20)
- น้องสีอ่อน (กระต่ายขาว) กลืนกับพื้นและกันเอง ไม่มีขอบตัด
- น้องสีเข้ม (ยูนิคอร์นม่วงเข้ม) หน้าและรายละเอียดจมหาย
- ไม่มีปาก → ทำสีหน้าได้แค่ตา · แก้มแดงจางมาก · ตาเป็นสีดำแบนๆ

## 1. แสงบนตัวน้อง (shader ของวัสดุ critter ตัวเดียวที่ทุกตัวใช้ร่วม, 0 draw call เพิ่ม)
- **เส้นขอบตัวการ์ตูน**: ขอบเงาเข้มบางๆ ตามแนวขอบตัว (คำนวณจากมุมมอง ไม่ใช่ mesh ซ้อน)
- **แสงขอบตัว (rim)**: ขอบด้านบนสว่าง สีตามแสงท้องฟ้าของช่วงเวลา (V20: กลางวันขาวอุ่น เย็นทอง คืนฟ้า)

## 2. หน้าตา (merged ใน mesh ตาเดิม, 0 draw call เพิ่ม)
- **ตาแวววาว**: ม่านตาไล่สีจากดำด้านบนเป็นสีอุ่นด้านล่างแบบตาการ์ตูน + ประกายเด่นขึ้น
- **แก้มแดง** ชัดขึ้น
- **ปาก + สีหน้า**: ปาก 4 แบบอยู่ใน mesh ตา แสดงทีละแบบด้วย shader (`model.setFace(k)`):
  1 ยิ้ม ω (ปกติ) · 2 อ้าปากดีใจมีลิ้น (เล่น กระโดด ป้อนอาหาร หน้าดีใจ V19) · 3 ปากคว่ำ (ป่วย น้อยใจ ร้องไห้ ปฏิเสธ) · 4 ปากจุ๊บ o (นอน)
- ตำแหน่งปากตามรูปจมูก/ปากกระบอก · นก (จะงอยปาก) ไม่มีปาก · spec.mouth = false ปิดได้
- กะพริบตา/หยีตา (scale.y ของ mesh ตา) ไม่ทำให้ปากขยับ
- **ตา ^^ ตอนดีใจ** (หน้าดีใจ V19, ตอนโดนลูบจนละลาย) แทนการหยีตาแบบเดิม · อยู่ใน mesh ตาเดียวกัน
- น้อง 17 สายพันธุ์ที่เคยมียิ้มแบบติดหน้า (extra 'smile') ใช้ปากใหม่ตรงจุดเดิม ไม่มีปากซ้อน
- งบสามเหลี่ยม: นับตัว/หน้าตามเดิม (1500 / 1800 ฯลฯ) โดยไม่รวมรูปปาก 4 แบบ (วาดทีละแบบ) · ปากรวมกันต้อง ≤ 60 สามเหลี่ยม (test)
