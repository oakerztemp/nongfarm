# CONTRACT V22 — ฉากมีชีวิต + รูปน้องจากโมเดล (Phase 5 รอบที่ 3)

> 2026-10-27 · ผู้ใช้สั่งเริ่ม V22 · ส่งภาพก่อน/หลังก่อน deploy · ไม่แตะ state / เศรษฐกิจ · ไม่เพิ่ม library

## 1. ลมพัด (engine, shader)
- หญ้าในลาน หญ้าป่า และดอกไม้ ไหวตามลมเบาๆ: ยอดขยับ โคนนิ่ง มีจังหวะลมกรรโชกเป็นระลอกพัดผ่านฉาก
- ทำใน vertex shader ของวัสดุหญ้า/ดอกไม้ (ไม่เพิ่ม draw call) · ระดับ low ปิด (นิ่งแบบเดิม)
- หญ้าป่าแยกวัสดุจากต้นไม้ (ต้นไม้ไม่โยก)

## 2. น้ำ
- ลำธาร: แสงระยิบบนผิวน้ำเลื่อนตามกระแส (shader ของลำธารเดิม, เฉพาะส่วนที่เป็นน้ำ)
- บ่อน้ำในลาน: แผ่นแสงสะท้อนวิบวับหมุนช้าๆ บนผิวน้ำ (1 draw call, medium ขึ้นไป)

## 3. กลีบดอกไม้ปลิว (skyfx)
- กลีบดอกสีชมพู/ขาว/เหลืองปลิวลอยผ่านลานช้าๆ ตอนกลางวัน (1 draw call; high 24 / medium 12 / low ไม่มี) · กลางคืนหายไป (หิ่งห้อยแทน)

## 4. โหมดเล่นแบบซูม
- ฉากหลังจางนุ่มเข้าหาสีท้องฟ้า (หมอกเริ่มหลังตัวน้องเสมอ ตามระยะกล้อง น้องตัวใหญ่ไม่โดนหมอก) ให้น้องเด่น · ฟองความคิดเล็กลงและกล้องเล็งให้ฟองไม่โดนแถบด้านบนบัง · ไม่ใช้ post-processing (มือถือลื่น)
- **หมายเหตุ**: แผนเดิมเสนอ bloom/DOF แบบ post-processing — ตัดออกเพราะต้องเพิ่ม library และหนักบนมือถือ; แสงเรืองของโคม/ออร่าใช้ halo เดิม (V20)

## 5. รูปน้องจากโมเดล 3D ในหน้า UI (js/ui/portraits.js ใหม่)
- การ์ดน้องในโหมดรายการ, หัวการ์ดรายละเอียด (sheet), เปลอนุบาล, มินิเกมโหมดรายการ: ใช้รูปที่ render จากโมเดล 3D ของน้องตัวนั้น (สายพันธุ์ ขั้นโต สีขน ไชนี่ Limited) แทนอีโมจิ → ทุกเครื่องเห็นเหมือนกันและตรงกับในลาน
- render ทีละรูปตอนเครื่องว่าง (renderer เล็กตัวเดียว 160 px) เก็บเป็น blob URL ใน cache ตาม "ลายเซ็น" ของโมเดล · ระหว่างรอแสดงอีโมจิเดิม
- คิวว่างเมื่อไรปิด WebGL context ตัวที่สองทันที (ไม่ถือ context ค้าง) · context หลุด = ไม่เก็บรูปว่าง ลองใหม่ด้วย context ใหม่
- เปลี่ยนเป็นกราฟิก "ต่ำ" = กลับเป็นอีโมจิทันทีแม้มีรูปใน cache
- ไม่ทำ (ใช้อีโมจิเดิม) เมื่อ: เครื่องไม่รองรับ 3D / ตั้งค่ากราฟิก "ต่ำ" / สายพันธุ์ไม่มีโมเดล
- ข้อความแจ้งเตือน/บันทึก ยังเป็นอีโมจิ (เป็นตัวอักษร)
