## 1. มือถือ: ฉากเต็มจอ ไม่ต้องเลื่อนหน้า (B)
- ที่ < 768 px ในแท็บลานโหมด 3D: `.b3` สูง = ความสูงจอที่เหลือ (100dvh − แถบบน `.app-top` − แถบเมนูล่าง − หัวลาน − ระยะขอบ) ขั้นต่ำ 320 px · main.js วัด `.app-top` และ `.tab-bar` ด้วย ResizeObserver แล้วตั้ง CSS var `--app-top-h` / `--tab-bar-h` บน `:root`
- เดสก์ท็อป: เดิม (clamp 340–560) แต่ไม่ต่ำกว่า 64vh เมื่อจอสูงพอ
- **เกณฑ์**: 375×812 แท็บลาน (มีแถบเควส + ชิปเทศกาล) → `document.scrollingElement.scrollHeight <= innerHeight + 1`
- **หัวลาน 3D เหลือแถวเดียว**: `[ชิปเทศกาลแบบย่อ (อีโมจิ + เหลือ N วัน)] … [16/16] [ลาน|รายการ]` — ชื่อ "🏡 ลานน้องๆ" ซ่อนบนมือถือ · ปุ่ม 📔 🖼️ 💌 ไม่อยู่ในหัวลาน 3D อีกแล้ว (ย้ายเข้าแมพ §2) · โหมดรายการ/ไม่มี 3D ยังมีปุ่มทุกปุ่มเหมือนเดิม
- **แถบเควส** บนมือถือ: บรรทัดเดียว (ลำดับ + ชื่อเควส + ปุ่ม) ซ่อนคำอธิบายและรางวัล (แตะชื่อ = toggle ขยาย)
- **ถาดอาหารพับได้**: ปุ่ม `.b3-tray-toggle` (C ใส่ markup) ที่ปลายซ้ายของถาด สลับ class `is-collapsed` บน `.b3-tray` (พับแล้วเหลือปุ่ม 🍽️ กลม) จำค่าใน localStorage `nongfarm_pref_tray` (try/catch)

## 2. ของในแมพคือปุ่ม (A ผัง · D โมเดล · C วาง/แตะ · B เปิดหน้าต่าง)
| ของ | แตะแล้ว | แทน |
|---|---|---|
| โรงนา (ประตู) | ถ้ามีไข่ในกระเป๋า + ตู้ฟักว่าง → `ctx.openEggPicker()`; ไม่งั้น toast บอกสถานะตู้ฟัก (กี่ใบ/ว่างกี่ช่อง) | ปุ่ม "🥚 ใส่ไข่" (ลบออก) |
| ตู้จดหมาย (ใหม่) | `ctx.openPostcards()` (โปสการ์ด 💌) · ธงแดงตั้งขึ้นเมื่อมีโปสการ์ดยังไม่อ่าน | ปุ่ม 💌 หัวลาน |
| กระดานไม้ (ใหม่) | `ctx.openJournal()` | ปุ่ม 📔 หัวลาน |
| ม้านั่งชมวิว (ใหม่) | ชีทเล็ก 2 ปุ่ม: 📸 ถ่ายรูป (เข้าโหมดถ่ายรูปเดิม) / 🖼️ อัลบั้ม (`ctx.openAlbum()`) | ปุ่ม 🖼️ หัวลาน (ปุ่ม 📸 บนฉากยังอยู่) |

- **หมุดบอกว่ากดได้** (C, DOM ใน `.b3-labels`, class `b3-pin`): ไอคอนกลม 30 px ลอยเหนืออาคาร: 🥚 บนโรงนา (เฉพาะตอนใส่ไข่ได้ เด้งเบาๆ), 💌+ตัวเลข บนตู้จดหมาย (เฉพาะมีโปสการ์ดใหม่), 🍳 โรงครัว, 📔 กระดาน, 📸 ม้านั่ง · แตะหมุด = แตะอาคาร · ซ่อนตอนโหมดถ่ายรูป/เล่นมินิเกม/ชีทเปิด · ในโหมด 🗺️ ยังแสดง
- **ตำแหน่ง** (A, petBehaviour.js): `export function landmarkSpots(tier) -> { mailbox:{x,z,r}, board:{x,z,r}, bench:{x,z,r} }` ทุก tier · เข้า `YARD.obstacles` · ข้อจำกัดเดียวกับ V23 §3 (อยู่ใน walk ของ tier, ห่าง prop/ครัว/decor spot/ชาม/แถวตู้ฟัก 3 ใบ/เปล/โรงนา ≥ 0.7 ขอบถึงขอบ, ลานกลาง ≤ 0.4·walk โล่ง) · แนวทาง: ตู้จดหมายหน้าลานใกล้ขอบรั้วด้านหน้า, กระดานข้างทางเดินหน้าโรงนา, ม้านั่งหันเข้ากลางลานใกล้บ่อ/ดอกไม้ · r ประมาณ mailbox 0.35, board 0.6, bench 0.7
- **โมเดล** (D, buildings.js): `buildMailbox(THREE,{gradient,tier}) -> { group, radius, height, setFlag(bool), update(dt,t), dispose }` (ธงหมุนขึ้น/ลงนุ่มๆ), `buildNoticeBoard(...) -> { group, radius, height, dispose }` (กระดานไม้มีกระดาษโน้ตสีๆ 3–4 แผ่น + หลังคาเล็ก), `buildBench(...) -> { group, radius, height, dispose }` (ม้านั่งไม้ + กระถางดอกไม้ข้างๆ) · โทนเดียวกับโรงครัว · แต่ละชิ้น ≤ 2 draw calls · ด้านหน้าหัน +z (C หมุนให้หันเข้ากลางลาน)

## 3. ป้อนผ่านชามข้าว (A logic · C ฉาก)
- `export function bowlFeedPlan(state, itemId, max = 4) -> petId[]` (pets.js, pure): น้องในลาน (ไม่อยู่เปล) ที่ `feedPet` จะสำเร็จ (ไม่หลับ ไม่ป่วยจนกินไม่ได้ ตาม careBlocker, hunger < 70) เรียงหิวมากสุดก่อน; ยาวไม่เกิน `min(max, จำนวนของชิ้นนั้นในกระเป๋า)`
- C: ลากอาหารไปปล่อยใกล้ชาม (ระยะ ≤ 1.0 จากชาม และไม่มีน้องในระยะ FEED_RANGE ที่ใกล้กว่า) → ชามมีอาหารพูน (emoji ลอยเหนือชาม) → น้องตาม plan เดินไป `bowlSpot(id)` ทีละตัว ถึงแล้ว `ctx.run(s => feedPet(s, id, itemId))` + ท่ากินเดิม · plan ว่าง = toast "ยังไม่มีน้องหิวเลย" และอาหารเด้งกลับ · ระหว่างลาก ถ้าเป้าคือชาม แสดงป้าย `.b3-feed-tag` "ชามข้าว · N ตัว"
- เศรษฐกิจ: เท่ากับป้อนทีละตัว (feedPet เดิม, 1 ชิ้น/ตัว)
