# ฟาร์มน้องๆ (NongFarm) — Game Design Document v1

> เกมเลี้ยงสัตว์สไตล์ทามาก็อตจิบนเว็บ + ส่งน้องๆ ไปทำไร่ทำสวน
> อ้างอิงแรงบันดาลใจ: ximon.io (เลี้ยงสัตว์บนเว็บ) — **แต่เราต่างตรงที่ไม่มีการต่อสู้** เน้นความหลากหลายของสัตว์ (100+ สายพันธุ์) และงานฟาร์ม

## 1. จุดขาย (ต่างจาก ximon)

| ximon.io | ฟาร์มน้องๆ |
|---|---|
| เทรนสเตตัสไปต่อสู้ PvP / ดันเจี้ยน | ไม่มีต่อสู้ — ส่งน้องไปทำไร่ ขุดดิน รดน้ำ ผสมเกสร เฝ้าไร่ ออกสำรวจ |
| เน้นสายพันธุ์น้อยแต่ลึก | **สัตว์ 100+ สายพันธุ์** ใน 8 ถิ่นอาศัย, 5 ระดับความหายาก, ✨ร่างชายนี่ 3% |
| ล็อกอินด้วย Public ID + passcode | **Login Google** (Firebase Auth) + โหมด Guest เล่นได้ทันที |
| ฟาร์มออฟไลน์เฉพาะ VIP | เวลาเดินจริงตลอด ออฟไลน์ก็โต (ปลูก/สำรวจ/หิว) แบบทามาก็อตจิ |

## 2. Core loop

```
ซื้อ/ได้ไข่ 🥚 → ฟักในตู้ฟัก (มีเวลา) → ได้น้อง (สุ่มสายพันธุ์ตามชนิดไข่)
   → เลี้ยง: ให้อาหาร / เล่น / อาบน้ำ / เก็บอึ / นอน / รักษา
   → ส่งน้องไปทำงาน: ประจำแปลงไร่ (ปลูกโตไวขึ้น + ผลผลิตมากขึ้น) หรือออกสำรวจ (ได้ของป่า)
   → เก็บเกี่ยว → ขาย 🪙 / เอามาเลี้ยงน้อง
   → ซื้อเมล็ด ไข่ใหม่ ขยายแปลง ขยายลาน → ปลดล็อกตามเลเวลผู้เล่น
   → สะสมให้ครบ "สมุดสัตว์" 📖
```

## 3. สัตว์ (เจ้าของ: Coder B)

- แสดงผลด้วย **emoji** (ทำให้ได้ 100+ สายพันธุ์โดยไม่ต้องวาด) ใส่กรอบ/แอนิเมชันน่ารัก
- **8 ถิ่นอาศัย = 8 ชนิดไข่**: ทุ่งนา (farm), ป่า (forest), น้ำ (water), ฟ้า (sky), แมลง (bug), ทุ่งหญ้าสะวันนา (savanna), ขั้วโลก (polar), ตำนาน (mystic)
- **ความหายาก**: common 60 / uncommon 25 / rare 10 / epic 4 / legendary 1 (น้ำหนักสุ่ม)
- **✨ Shiny 3%**: สีเพี้ยน (CSS hue-rotate) + ประกาย + พลังงาน x1.1
- **นิสัย (personality) สุ่มตอนฟัก**: ขยัน / ขี้เกียจ / ตะกละ / ร่าเริง / ขี้อาย / ซน — ปรับค่า decay หรือพลังงาน
- **อาหาร**: แต่ละสายพันธุ์มี diet tags + ของโปรด 1 อย่าง (กินของโปรด = สุข x2)
- **ความถนัดงาน 8 แบบ** (0–3): ขุด `dig`, รดน้ำ `water`, ผสมเกสร `pollinate`, เฝ้า `guard`, แบก `carry`, หาของ `forage`, จับปลา `fish`, บิน `fly`
  เช่น 🐹 ขุด 3, 🐝 ผสมเกสร 3, 🐘 รดน้ำ 3 + แบก 3, 🐕 เฝ้า 3, 🦦 จับปลา 3, 🦅 บิน 3

### สเตตัสทามาก็อตจิ (0–100)
| สเตตัส | ลดลง/ชม. | เติมด้วย |
|---|---|---|
| อิ่ม `hunger` | 6 | อาหาร |
| สุข `happy` | 4 | เล่น / ของเล่น / ของโปรด |
| พลัง `energy` | +3 ตอนว่าง, −12 ตอนทำงาน, +20 ตอนนอน | นอน |
| สะอาด `clean` | 3 (+3 ต่ออึ 1 ก้อน) | อาบน้ำ / เก็บอึ |

- **อึ 💩**: เกิดทุก ~2 ชม. หลังกิน (สูงสุด 3 ก้อน) ต้องเก็บ
- **ป่วย 🤒**: ถ้าอิ่มหรือสะอาด = 0 ติดกันเกิน 2 ชม. → ป่วย ทำงานไม่ได้ สุขลด x2 → รักษาด้วยยา 💊
- **ไม่มีตายถาวร** (เกม cozy) และตอนออฟไลน์ค่าลดลงครึ่งเดียว
- **โต 4 ขั้น**: เบบี้ 🍼 → เด็ก → โตเต็มวัย → มาสเตอร์ 👑 (XP 0 / 50 / 200 / 600) พลังงาน x0.5 / x0.8 / x1.0 / x1.3 — เบบี้ออกสำรวจไม่ได้

## 4. ฟาร์ม (เจ้าของ: Coder C)

- **แปลงไร่** เริ่ม 4 แปลง ซื้อเพิ่มได้ถึง 16 (ราคาไต่ขั้น)
- ปลูกเมล็ด → โตตามเวลาจริง → เก็บเกี่ยว
- **ความเร็วโต** = 1 + 0.2 (ถ้ารดน้ำแล้ว) + 0.3 × พลังของน้องที่ประจำแปลง
- **พลังน้อง** = (0.5 + ความถนัดสูงสุดในงานที่พืชต้องการ) × ขั้นโต × อารมณ์ × นิสัย × shiny
- **ผลผลิต** = สุ่ม [min,max] ของพืช + floor(พลัง/2)
- น้องที่ทำงานเสีย energy และได้ XP 1/นาที — energy หมดหรือป่วย → กลับลานเอง
- **พืช 16 ชนิด** (2 นาที – 4 ชม.) ปลดล็อกตามเลเวล: แครอท ข้าวโพด มะเขือเทศ มันฝรั่ง ผักกาด สตรอว์เบอร์รี มะเขือม่วง พริก ฟักทอง แตงโม ทานตะวัน ข้าว องุ่น บร็อกโคลี มันเทศ สับปะรด
- **ออกสำรวจ 4 โซน**: 🌲 ป่าใหญ่ (forage), 🏞️ บึง (fish), ⛰️ ภูเขา (dig), ☁️ ปุยเมฆ (fly) — 5–60 นาที ได้ของป่าตามพลัง
- **ร้านค้า**: เมล็ด, อาหาร, ของใช้ (สบู่ ของเล่น ยา ปุ๋ย), ไข่, ขยายแปลง, ขยายลาน
- **กระเป๋า**: ขายของ / ดูของ

## 5. ผู้เล่น / ระบบ (เจ้าของ: Coder A)

- **Login Google** ผ่าน Firebase Auth (popup) — save บน Firestore `users/{uid}`
- **Guest mode** เล่นได้ทันทีด้วย localStorage; ล็อกอินครั้งแรกจะย้าย progress guest ขึ้น cloud
- ถ้ายังไม่ตั้งค่า Firebase ปุ่ม login จะ disabled พร้อมคำแนะนำ เกมยังเล่น Guest ได้
- เลเวลผู้เล่น: XP จากเก็บเกี่ยว/ฟักไข่/สำรวจ — XP ที่ต้องใช้ = round(50 × level^1.5)
- รางวัลรายวัน: 50 🪙 + เมล็ดสุ่ม 3 เม็ด
- เวลาออฟไลน์: ตอนโหลดเกมคำนวณย้อนหลังสูงสุด 72 ชม. (ทีละ 60 วินาที)
- เริ่มเกม: 100 🪙, ไข่ทุ่งนา 1 ใบ, เมล็ดแครอท 3, อาหารเม็ด 2, แปลง 4, ลาน 3 ช่อง, ตู้ฟัก 1 ช่อง

## 6. หน้าจอ / UX

- Mobile-first (เหมือนเครื่องทามาก็อตจิในมือ) มือถือ = tab bar ด้านล่าง, จอใหญ่ = ด้านบน
- Header: ชื่อฟาร์ม, เลเวล + แถบ XP, 🪙 เหรียญ, สถานะ save, ปุ่ม Login/ผู้ใช้
- แท็บ: 🏠 ลาน (B) · 🌾 ไร่ (C) · 🧭 สำรวจ (C) · 🛒 ร้าน (C) · 🎒 กระเป๋า (C) · 📖 สมุดสัตว์ (B)
- ธีม: pastel cozy, ฟอนต์ไทย **Mali** (Google Fonts), รองรับ dark mode
- น้องมีแอนิเมชันเด้ง, บับเบิลอารมณ์ (😋 💤 💢 🤒), อึ 💩 โผล่ข้างตัว

## 7. Tech stack

- Vanilla JS (ES modules) ไม่มี build step — เครื่องนี้ไม่มี Node
- Firebase JS SDK v10.12.2 จาก gstatic CDN (Auth + Firestore)
- รันทดสอบ: `python -m http.server 8787` ในโฟลเดอร์เกม
- Client-authoritative (เกมงานอดิเรก ยอมรับว่าโกงได้ — ไม่มีเงินจริง)
