  - push `main` แล้ว GitHub Actions จะรัน test และ deploy ขึ้น GitHub Pages
  - เครื่องนี้ไม่มี `gh` จึงเช็คสถานะ Actions ผ่าน REST API แบบไม่ต้องล็อกอิน

## 3. งานค้าง (เรียงตามความสำคัญ)

0. **มือถือ (แก้แล้ว 2026-10-26 ยังไม่ได้ยืนยันบน iPhone จริง):** แถบหมวดร้านค้าขึ้นบรรทัดใหม่แทนการเลื่อน; modal ใช้ `100dvh` + safe-area (เดิม `100vh` ทำให้ก้น modal จมใต้แถบ Safari)

1. **ลอยกระทงปี 2570:** เพิ่มแถวใน `SPECIALS` (`js/data/festivals.js`) **ก่อนสิ้น พ.ย. 2569** ไม่อย่างนั้นชฎา ผ้าสไบ โคมล้านนา และกระทงยักษ์จะแลกไม่ได้จนถึงปีหน้า ต้องเช็ควันจริงก่อนใส่
2. **ชุดที่คอมองเห็นยาก:** ห่วงยาง ผ้าสไบ ผ้าพันคอ และกระดิ่ง อยู่ใต้คางจากมุมกล้องด้านบน ต้องย้ายตำแหน่งหรือทำให้ใหญ่ขึ้น ค้างมาตั้งแต่ V9
3. **ยังไม่ได้เห็นด้วยตา:**
   - มดเดินแถว (ต้องมีมดอย่างน้อย 2 ตัว), หนอนคืบ, จิ้งหรีดร้องตอนกลางคืน, ผึ้งตอมดอกไม้
   - ท่าพิเศษวาฬ อินทรี และด้วง
   - การแปลงเซฟบนคลาวด์จริงเป็น v9 บนบัญชีผู้ใช้
4. **ป้ายชื่อทับกันในหน้า gallery** (QA เล็ก)
5. **โฟลเดอร์ `.claude/` ในโฟลเดอร์เกม:** agent สร้างผิดที่และไม่มีผลกับเกม ผู้ใช้ต้องลบเอง และห้าม commit

## 5. วิธีทำงานที่ผู้ใช้ชอบ (ทำตามทุกรอบ)

1. **วางแผนก่อนเสมอ:** เขียน `docs/CONTRACT_V<n>.md` ให้มีสเปก เจ้าของงาน เกณฑ์ผ่าน และเกณฑ์ตัวจำลองเศรษฐกิจถ้าแตะรายได้หรือราคา แล้วลงมือได้เลยโดยไม่ต้องรออนุมัติแผน
2. **แบ่งงานให้ทีม:** หัวหน้า (Opus) แบ่งให้ coder 3 คน (sonnet) ทำพร้อมกัน
   - **A core:** state, migration, logic, test
   - **B UI/behaviour:** หน้าจอ, ฉาก 3D, ท่าทางน้อง
   - **C content/econ:** โมเดล 3D, ข้อมูล, ตัวจำลองเศรษฐกิจ
3. **reviewer (opus)** ตรวจโค้ด แล้วหัวหน้าตรวจเองในเบราว์เซอร์ด้วยตาอีกรอบ
4. **ถามผู้ใช้ก่อน commit, push และ deploy ทุกครั้ง**
5. **สื่อสารภาษาไทย**

## 6. ข้อควรระวัง (เคยพังมาแล้ว)

- **รัน test:** `python tests/run_tests.py` ต้องจบที่ `ALL PASS` ชุด test รันใน Edge แบบ headless
  - **ห้ามเปิด `tests/index.html` บนพอร์ต 8790:** ชุด test ล้าง localStorage ทั้ง origin ทำให้เซฟโชว์ "ฟาร์มเทพ" หาย
- **พอร์ต:** launch config อยู่ที่ `SANDBOX_CLAUDE\.claude\launch.json`
  - "NongFarm" 8787
  - "NongFarm Showcase" 8790 (ห้ามแตะ)
  - coder B 8795, coder C 8796
  - ให้ agent เปิดแท็บของตัวเองเสมอ (`tabs_create`) และใส่ `tabId` ในทุก action
- **รูปแบบขึ้นบรรทัดใหม่:** หลายไฟล์ใน repo เป็น CRLF แต่ agent มักเขียนเป็น LF
  - ก่อน commit ให้เช็ค `git ls-files --eol` และแปลงกลับให้ตรง index
  - ถ้าไม่แปลง diff จะบวมเป็นหมื่นบรรทัด
- **test ที่ใช้ `withFakeNow` ต้องใช้ `now()` ไม่ใช่ `Date.now()`:** เคยพังเพราะวันจริงเปลี่ยน
- **ตัวจำลองเศรษฐกิจ:** `runSim` ปลอมทั้ง `Math.random` และ `Date.now` เพราะ `uid()` ใช้ `Date.now` ถ้าเพิ่มอะไรที่สุ่มหรือใช้เวลา ต้องทำให้ผลเหมือนเดิมทุกรอบ
- **3D ใน browser pane:**
  - ต้องเปิดด้วย `?soft3d=1`
  - `requestAnimationFrame` ทำงานเฉพาะตอนถ่าย screenshot ถ้าจะดูฉากเคลื่อนไหว ให้แก้ rAF ชั่วคราวใน console (ห้ามแก้ในโค้ด)
  - ถ่ายภาพคมด้วย `__b3debug.world.snapshot()` (`?debug=1`)
  - คำสั่ง debug อื่นใน `__b3debug`: `tap`, `krathong`, `night`, `fest`, `breedScene` ฯลฯ
- **เปิดเทศกาลที่ต้องการ:** ใช้ `?debug=1&fest=<id>` เช่น `fest_loykrathong` ใช้ได้เฉพาะ localhost และไม่บันทึกลงเซฟ
- **cache ไฟล์เก่าในเบราว์เซอร์:** `fetch(url, {cache:'reload'})` ทุกไฟล์ที่แก้ แล้วค่อยรีโหลดหน้า
- **GitHub Pages** แคช `index.html` ประมาณ 10 นาที เช็คเวอร์ชันจาก `?v=<sha>` ใน index.html
- **Google login** ใช้ใน browser pane ไม่ได้ ต้องทดสอบผ่าน Claude in Chrome ผู้ใช้มีหลายบัญชี จึงต้องให้ผู้ใช้เลือกบัญชีเอง
- **ทิศหมุนชิ้นส่วนโมเดล:** เคยกลับทิศ (หางนกยูง ขาฟลามิงโก) ให้ยึดคอมเมนต์ใน `js/data/models.js` และตรวจด้วยภาพเรนเดอร์ ไม่ใช่แค่ตัวเลข

## 7. กติกาเศรษฐกิจที่ล็อกไว้แล้ว

- **ผสมพันธุ์:** ค่าผสม = 3 เท่าของราคาไข่ที่แพงกว่า เพื่อนซี้จ่าย ×0.8 (`BREED_COST_MULT`, `BREED_FRIEND_MULT`) ถ้าต่ำกว่านี้จะกลายเป็นที่ปั๊มผงดาว
- **เทศกาล:** ไม่ให้เหรียญและไม่ให้ผงดาว ให้แค่ของแต่ง กระทงใช้สมุนไพร 3 กับไม้ 1
- **ลานให้ของ:** ต้องไม่เกิน 20% ของรายได้ทุกวัน
- **ความเร็วเกม:** วันที่ 14 รายได้ไม่เกิน 4,500 เหรียญ/ชม. เวลาถึงลาน M/L/XL ต้องอยู่ใน ±25% ของค่าฐาน V6
- **ห้ามมีลูปซื้อแล้วขายได้กำไร**
