# ฟาร์มน้องๆ — ข้อเสนอ "โลกที่มีชีวิต" (ร่าง, 2026-10-23)

> โจทย์ผู้ใช้: อยากเห็นความน่ารักของน้องๆ มากกว่านี้ ตอนนี้น้องอยู่แค่ในการ์ด ไม่รู้สึกเหมือนเลี้ยงจริง
> สังเคราะห์จาก brainstorm ของ Coder A/B/C + Reviewer — **ยังไม่อนุมัติ**

## ทำไมตอนนี้รู้สึกเหมือนตาราง Excel (Reviewer)
- น้อง 1 ตัว = การ์ดที่มีแถบตัวเลข 4 เส้น + ปุ่ม 6 ปุ่ม, ตัวน้องเล็กอยู่มุมการ์ด
- ทำอะไรให้น้อง น้องไม่มีปฏิกิริยา — มีแค่ toast กับแถบที่ขยับ
- น้องไม่มี "ที่อยู่" ไม่เคลื่อนไหว ไม่รู้จักกันและไม่รู้จักผู้เล่น
- ที่ไร่ น้องเป็นแค่ชิปในช่อง

## หลัก 5 ข้อ (จากเกมที่คนรัก: Tamagotchi, Neko Atsume, Finch, ximon)
1. โลกมาก่อน เมนูมาทีหลัง — แตะน้องถึงเห็นตัวเลข
2. ชีวิตตอนว่าง — เดิน นั่ง หลับ หันมามองเองแบบสุ่มช้าๆ
3. ทุกการกระทำมีปฏิกิริยาที่มองเห็น — อาหารลอยไปหา เคี้ยว หัวใจเด้ง
4. ความต้องการแสดงบนตัว — หิว = ฟองความคิดเป็นของโปรด, สกปรก = แมลงวัน, ง่วง = ขดตัว Zzz
5. นิสัยมองเห็นได้ — ขี้เกียจนอนบ่อย, ร่าเริงกระโดด, ขี้อายหลบหลังตัวอื่น

## แผน 4 ขั้น

| ขั้น | อะไร | เจ้าของ | แรง |
|---|---|---|---|
| L1 | **คอกมีชีวิต**: ฉากเต็มความกว้าง (~60% จอ) น้องเดินเล่น ขนาดตามวัย ฟองความต้องการ อึบนพื้นแตะเก็บได้ หลับขดตัว ตู้ฟักเป็นรังมุมฉาก แตะน้อง = ลูบหัว (หัวใจเด้ง, แต้มผูกพันตามเพดานรายวัน) + แผ่นข้อมูลด้านล่าง; การ์ดเดิมย้ายไปเป็นปุ่ม "มุมมองรายการ" | A (เอนจินฉาก) + B (คอก) | M |
| L2 | **ปฏิกิริยา**: ถาดอาหาร แตะอาหารแล้วแตะน้อง (หรือลาก) → อาหารลอยไป เคี้ยว หัวใจ; พิธีฟักไข่ (สั่น → แตก → น้องเด้งออกมาเดินมาหา พูดชื่อ) | B | M |
| L3 | **น้องทำงานที่ไร่ให้เห็น**: เวทีดินบนการ์ดแปลง น้องตัวใหญ่ยืนทำท่าตามงาน (ขุด=กระโดดลง, รดน้ำ=เอียง+หยดน้ำ, ผสมเกสร=บินซิกแซก, เฝ้า=โยก); คอมโบมีประกาย; เก็บเกี่ยว = พืชเด้ง + ไอเท็มลอยไปกระเป๋า; น้องว่างเดินเล่นที่ลานบนสุดของไร่ | C (+A เลเยอร์เอฟเฟกต์) | M |
| L4 | **บุคลิกในการเคลื่อนไหว**: 6 แบบ (เดิน/กระโดด/บิน/ว่ายในบ่อ/คลาน/บินวน) ผูกกับสายพันธุ์, นิสัย+ความสามารถพิเศษปรับท่า, กลางวัน-กลางคืนตามเวลาจริง, น้องว่างๆ หันมาคุยกัน 💬 | B + A | M |
| ภายหลัง | อัปเกรดภาพจาก emoji เป็นพิกเซลอาร์ต/SVG (ต้องมีคนออกแบบ) | — | L |

## สถาปัตยกรรม (Coder A)
- DOM + CSS transform (ไม่ใช้ canvas): น้องแต่ละตัวเป็น `<button>` → แตะ/โฟกัส/โปรแกรมอ่านหน้าจอได้ฟรี
- `js/scene.js` เอนจินเล็ก (~150 บรรทัด) แกนไม่แตะ DOM: requestAnimationFrame 30 fps, หยุดเมื่อแท็บซ่อน, prefers-reduced-motion = ท่านิ่ง
- ฉากอยู่นอกการ re-render (morph ข้าม), sync เฉพาะรายชื่อ/สถานะน้องเมื่อ state เปลี่ยน
- ตำแหน่งน้องเป็นของตกแต่ง **ไม่เซฟ** (ไม่กระทบระบบเซฟ/rev)
- การ์ดเดิมยังอยู่เป็นมุมมองรายการ (accessibility + คนเลี้ยง 20 ตัว)

## ข้อควรระวัง
- มือถือสเปกต่ำ: แสดงพร้อมกันไม่เกิน ~8 ตัว + ฟอง "+N", เคลื่อนแค่ transform/opacity
- แตะโดนน้องที่กำลังเดิน: หยุดน้องตอนแตะ, พื้นที่แตะ ≥ 44px
- ความเหนื่อยตา: ท่าว่างช้าและนิ่งเป็นช่วงๆ เก็บเอฟเฟกต์ใหญ่ไว้ตอนผู้เล่นทำอะไร
- ห้ามซ่อนข้อมูลสำคัญ: หิว/ป่วยต้องเห็นชัดเสมอ
