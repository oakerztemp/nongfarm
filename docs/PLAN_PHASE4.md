## V15 — เก็บงานด่วน + สะวันนา
1. **ลอยกระทงปี 2570** (เส้นตายสิ้น พ.ย. 2569): เพิ่มแถวใน `SPECIALS` หลังเช็ควันลอยกระทงจริงของปี 2570 จากแหล่งทางการก่อนใส่
2. **ชุดที่คอมองไม่เห็น** (ห่วงยาง ผ้าสไบ ผ้าพันคอ กระดิ่ง): ย้ายขึ้น/ขยายให้เห็นจากกล้องมุมบน ค้างมาตั้งแต่ V9
3. **ป้ายชื่อทับกันในหน้า gallery** (QA เล็ก)
4. **โมเดล 3D สะวันนา 11 ตัว** (กิ้งก่า อูฐ อูฐสองโหนก ม้าลาย จิงโจ้ ไบซัน จระเข้ ช้าง ยีราฟ ฮิปโป แรด เสือดาว) ใช้สูตรชิบิตั้งแต่ต้น ส่งภาพให้ดูก่อนใส่จริงเหมือนรอบยูนิคอร์น
- เกณฑ์ผ่าน: test ALL PASS, งบสามเหลี่ยม, ตรวจภาพทุกตัว, ลอยกระทง 2570 แลกของได้ในช่วงวันที่ถูกต้อง

## V16 — ทำอาหารป้อนน้อง + ขั้วโลก
1. **ครัวในลาน**: เอาพืชจากไร่ + ของป่ามาทำเมนู (เช่น สลัดแครอท ซุปฟักทอง พายเบอร์รี่) แล้วลากไปป้อนน้องในลาน 3D
   - ได้บัฟชั่วคราว (เช่น ทำงานไร่เร็วขึ้น 1 ชม., หัวใจเพิ่ม) + ท่ากินพิเศษ
   - ร่างกติกาเศรษฐกิจ: เมนูขายเป็นเหรียญไม่ได้ (กันลูปซื้อ→ขาย), บัฟซ้อนกันไม่ได้, รายได้วันที่ 14 ≤ 1.10 เท่าของตอนไม่ใช้ครัว และยังอยู่ใต้ 4,500/ชม.
2. **โมเดล 3D ขั้วโลก 9 ตัว** (เพนกวิน แมวน้ำ กระต่ายหิมะ ฮัสกี้ แมวไซบีเรีย แกะภูเขา เบลูก้า จามรี หมาป่าหิมะ)
- เกณฑ์ผ่าน: ตัวจำลองเศรษฐกิจผ่านเกณฑ์ใหม่ + เกณฑ์เดิมทั้งหมด
