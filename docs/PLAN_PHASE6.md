## 0. สิ่งที่เจอตอนสำรวจ

**ลานแน่น (ตัวเลข)**
- ลานเป็นวงกลม รัศมีที่เดินได้: S 4.3 / M 5.0 / L 5.6 / XL 6.2
  - ลาน XL (16 ตัว) มีพื้นที่ประมาณ 121 ตร.หน่วย
  - โรงนา บ่อ ชิงช้า แปลงดอกไม้ ชามข้าว และของแต่ง กินที่ไปเกือบครึ่ง
  - น้องจึงเหลือที่ประมาณ 4 ตร.หน่วยต่อตัว น้องตัวใหญ่ (หมี วัว) ตัวเดียวก็กินที่ไปราว 1–1.5
- กล้องล็อกระยะไว้ที่ลานขนาด M ทุกขนาด ทำให้ลาน XL ล้นขอบจอ และทุกอย่างดูอัดกันอยู่กลางจอ
- ทุกอย่างอยู่ในวงรั้ววงเดียว ไม่มีโซน ไม่มีทางเดินเชื่อม นอกรั้วเป็นทุ่งหญ้ากับต้นไม้อย่างเดียว

**UI หน้าลาน (มือถือ 375 px)**
- แถบบนกินจอไปเกือบ 40% ก่อนถึงตัวฉาก:
  - หัวเกม และเควส "ฟักไข่ใบแรก"
  - ปุ่มกลม 3 ปุ่ม (ครัว บันทึก อัลบั้ม) และปุ่มสลับลาน/รายการ
  - แบนเนอร์เทศกาล
- ถาดอาหารอยู่ใต้ฉาก มือถือต้องเลื่อนหน้าลงถึงจะกดได้

**อาหารหาย:** ไล่โค้ดแล้วลองจริง ทำสลัดแล้วอาหารเข้ากระเป๋าครบ และขึ้นในถาดอาหาร ส่วนทำอาหารไม่ได้ทิ้งของ จึงน่าจะหายตอนหลังทำ มี 4 ทางที่เป็นไปได้:
1. **อาหารจมอยู่กลางถาด:** ถาดเรียงตามชื่อภาษาไทย ปนกับพืชผลเป็นสิบอย่าง บนมือถือถาดล้นจอด้านข้าง จานที่เพิ่งทำจึงอาจอยู่นอกจอ
2. **ลากไปป้อนผิดตัว:** ระบบให้กินกับตัวที่ใกล้จุดปล่อยที่สุดในระยะ 1.2 หน่วย พอน้องยืนเบียดกัน 16 ตัว อาหารไปเข้าปากตัวข้างๆ
   - ข้อความแจ้งขึ้นแป๊บเดียวแล้วหาย
3. **เลือกอาหารค้างไว้:** แตะอาหารในถาดแล้ว แตะน้องตัวต่อไปจะป้อนทันที ทั้งที่ตั้งใจแค่จะดูน้อง
4. **เล่นหลายเครื่อง (มือถือกับคอม):** เซฟใหม่กว่าจะชนะทั้งก้อน ของที่ทำบนเครื่องที่แพ้จะหายจากเกม (ระบบสำรองเซฟไว้ให้)

ข้อ 1–3 เกิดบ่อยขึ้นเมื่อลานแน่น จึงแก้พร้อมกับแมพ ข้อ 4 ต้องถามผู้ใช้ก่อน

## V23: แมพใหญ่ จัดโซน ย้ายครัวเข้าแมพ แก้อาหารหาย

1. **ลานกว้างขึ้นประมาณ 2 เท่า**
   - รัศมีที่เดินได้: S 5.0 / M 6.4 / L 7.6 / XL 9.0
   - เป้าหมาย: เหลือที่ 9 ตร.หน่วยต่อตัวขึ้นไป หลังหักพื้นที่ของในลาน
   - ราคาและวัสดุขยายลานเท่าเดิม (ไม่แตะเศรษฐกิจ)
2. **กล้องแบบแมพ**
   - เปิดมาเห็นลานเล่นตรงกลาง และน้องมีขนาดบนจอเท่าเดิม
   - ลากเพื่อเลื่อนดูได้ทั่วแมพ ซูมออกได้ไกลขึ้น
   - มีปุ่ม 🗺️ "ดูทั้งฟาร์ม" สำหรับมองจากมุมสูงทีเดียว
3. **จัดเป็นโซน มีทางเดินดินเชื่อม**
   - กลาง: ลานหญ้าให้น้องเล่น
   - หลัง: โรงนาและตู้ฟักไข่
   - ซ้าย: **โรงครัว**
   - ขวา: บ่อน้ำต่อกับลำธาร
   - หน้า: ชามข้าว และมุมนั่งเล่น
   - รั้วเปลี่ยนจากวงกลมเป็นทรงโค้งแบบธรรมชาติ
4. **โรงครัวเป็นอาคารในแมพ**
   - แตะที่โรงครัว กล้องจะเลื่อนไปหาแล้วเปิดหน้าทำอาหาร
   - ระหว่างทำ ปล่องไฟมีควัน
   - เอาปุ่ม 🍳 ออกจากแถบบน
5. **แก้อาหารหาย**
   - จานที่ทำแล้วอยู่หน้าสุดของถาด มีป้าย "ใหม่"
   - ทำเสร็จ จานลอยจากโรงครัวเข้าถาด ให้เห็นว่าไปอยู่ไหน
   - ตอนลากอาหาร น้องตัวที่จะได้กินมีวงสีและชื่อขึ้นเหนือหัว ปล่อยตรงที่ไม่มีน้อง อาหารเด้งกลับถาด
   - แตะเลือกอาหารแล้ว ถ้าไม่ได้ป้อนภายใน 8 วินาที หรือแตะที่ว่าง ยกเลิกการเลือกเอง
   - ข้อความ "X กิน Y" ค้างนานขึ้นสำหรับจานพิเศษ และลงสมุดบันทึกทั้งตอนทำและตอนกิน
6. **น้องกระจายตัว:** จุดเดินเล่นของแต่ละตัวกระจายทั่วลาน และน้องชอบโซนต่างกันตามนิสัย (ขี้เซาอยู่ใกล้โรงนา ตะกละวนแถวครัว)
7. **เซฟเดิมไม่เสีย:** ของแต่งที่วางไว้ย้ายตามสัดส่วนลานใหม่ ไม่ทับกัน

**แบ่งงาน**

| ผู้ทำ | งาน |
|---|---|
| A core | ย้ายตำแหน่งของแต่ง (migrate), เวลาหมดของการเลือกอาหาร, บันทึกลงสมุด, test |
| B UI | ถาดอาหาร (จานใหม่หน้าสุด, ป้าย), ปุ่ม 🗺️, เอาปุ่ม 🍳 ออก, หน้าครัวเปิดจากอาคาร |
| C ฉาก 3D | ขนาดลาน, กล้อง/เลื่อนดู, โซนและทางเดิน, รั้วโค้ง, ชื่อน้องตอนลาก, จานลอยเข้าถาด, การกระจายตัว |
| D content | โมเดลโรงครัว (ปล่องไฟ, ควัน), ซุ้ม, ทางเดิน, ผังจุดวางของ |

**เกณฑ์ผ่าน**
- น้อง 16 ตัวในลาน XL: ระยะเฉลี่ยถึงตัวที่ใกล้สุดต้องเป็น 1.5 เท่าของเดิมขึ้นไป (วัดจาก test)
- ไม่มีน้องติดอยู่ในอาคารหรือในบ่อ
- มือถือ 375 px ยัง 30 fps
- draw call เพิ่มไม่เกิน 15
- ภาพก่อน/หลัง เดสก์ท็อปและมือถือ
- `python tests/run_tests.py` ผ่านทั้งหมด

## V24: หน้าลานโล่ง และของในแมพใช้งานได้จริง

1. **บนมือถือ ฉากเต็มจอตั้งแต่ใต้หัวเกมถึงแถบเมนูล่าง ไม่ต้องเลื่อนหน้า**
   - ถาดอาหารลอยอยู่ในฉาก (หุบได้)
   - แบนเนอร์เทศกาลและเควสหดเป็นป้ายเล็กมุมจอ แตะเพื่อดูรายละเอียด
2. **ของในแมพคือปุ่ม**

   | ของในแมพ | ทำอะไร |
   |---|---|
   | โรงนา | ตู้ฟักไข่ / ใส่ไข่ (แทนปุ่ม "ใส่ไข่") |
   | ตู้จดหมาย | โปสการ์ด (แทนไอคอน 📬) |
   | กระดานไม้หน้าโรงนา | สมุดบันทึก และเควส (แทนปุ่ม 📔) |
   | ชามข้าว | ลากอาหารใส่ชาม น้องที่หิวจะเดินมากิน (ป้อนทีละหลายตัว) |
   | ม้านั่งชมวิว | โหมดถ่ายรูปและอัลบั้ม (แทนปุ่ม 📷 และ 🖼️) |

   - แตะของในแมพแล้วมีป้ายชื่อเด้งขึ้น ให้รู้ว่ากดได้
3. แถบบนของหน้าลานเหลือแค่ ลาน/รายการ กับ ตกแต่ง

**แบ่งงาน**

| ผู้ทำ | งาน |
|---|---|
| A | ป้อนผ่านชามข้าว (กติกาเดิม แค่เลือกน้องที่หิวที่สุดให้) + test |
| B | จัดหน้าลานบนมือถือและเดสก์ท็อปใหม่ |
| C | แตะอาคารแล้วกล้องเลื่อนไปหา, ป้ายชื่อ, ไฮไลต์ |
| D | โมเดลตู้จดหมาย กระดาน ม้านั่ง |

**เกณฑ์:** มือถือ 375×812 เปิดหน้าลานแล้วไม่ต้องเลื่อนหน้าเพื่อป้อนอาหาร ทำอาหาร หรือใส่ไข่

## V25: แมพสวย

1. **พื้น:** ไล่สีหญ้าเป็นหย่อม มีดินตามทางเดิน ขอบทางมีดอกไม้และก้อนหิน มีพุ่มไม้เตี้ยแทนรั้วบางช่วง
2. **อาคาร:** โรงนา โรงครัว ตู้ฟักไข่ มีรายละเอียดมากขึ้น เช่น หน้าต่างมีแสง กระถางดอกไม้ ป้ายชื่อฟาร์ม
3. **กลางคืน:** ไฟตามทางเดิน หน้าต่างโรงครัวและโรงนาเปิดไฟ (ต่อจาก V20)
4. **ขอบแมพ:** ทุ่ง ต้นไม้ และลำธารต่อเนื่องกับลาน ไม่ดูเป็นเกาะ มีสะพานไม้ข้ามลำธาร
5. ใช้ระบบแสง หมอก และลมของ Phase 5 เดิม ไม่เพิ่ม library

**แบ่งงาน**

| ผู้ทำ | งาน |
|---|---|
| C | พื้น ทางเดิน ขอบแมพ |
| D | รายละเอียดอาคารและของประดับ |
| B | ป้ายชื่อฟาร์ม |
| A | test ประสิทธิภาพ (draw call และจำนวนสามเหลี่ยมตามระดับกราฟิก) |
