## Phase 0 — ฐานรากก่อนเพิ่มฟีเจอร์ (S, ~1 รอบทีม)

ทำก่อนเพราะ v2 จะเปลี่ยนโครง state หลายจุด และบั๊กรอบแรกเกือบทั้งหมดอยู่ที่รอยต่อระหว่างโมดูล

| งาน | เจ้าของ |
|---|---|
| `tests.html` — unit test ในเบราว์เซอร์สำหรับ state/pets/farm/migrate + สคริปต์ Python รันผ่าน headless Edge (ผ่าน = `ALL PASS`) | A |
| Save migration แบบมีเลขเวอร์ชัน (`version` 1→2→…) + ไฟล์ save ตัวอย่าง (v1, เสีย, เก่า) ที่ทุก release ต้องโหลดผ่าน | A |
| ตัวจำลองเศรษฐกิจ: เล่นอัตโนมัติ 14 วัน รายงาน 🪙/ชม. ตามเลเวล, fail ถ้ามีลูปซื้อ-ขายกำไร | C |
| แก้เล็ก: ถามชื่อฟาร์มหลัง logout, ลดการ re-render ที่ทำแอนิเมชันกระตุก (DOM patch) | A |

## Phase 1 — "เล่นแล้วรู้ว่าต้องทำอะไร" (M) + เปิดให้เล่นจริง

| งาน | ผลต่อผู้เล่น | เจ้าของ |
|---|---|---|
| ภารกิจมือใหม่: ฟัก→ให้อาหาร→ปลูก→ส่งน้องช่วย→สำรวจ พร้อมรางวัลไข่/เหรียญ | 10 นาทีแรกไม่ว่าง | A (ระบบเควส) + B/C (เงื่อนไข) |
| กระดานออเดอร์รายวัน 3 ใบ + ออเดอร์ใหญ่รายสัปดาห์ (รางวัลไข่พิเศษ) | ทุกวันมีเป้าหมาย, บังคับปลูกหลากหลาย | C |
| อัปเกรดตู้ฟัก (1→3 ช่อง) + ไข่หล่นจากการสำรวจ/รางวัลรายวัน | สะสมสัตว์ได้เร็วขึ้นตามความก้าวหน้า | B + C |
| รางวัลสมุดสัตว์ (ครบ 3/6/ทั้งหมดต่อถิ่น) + ตัวซ้ำแลกเป็น "ผงดาว" ไว้สุ่ม shiny | RNG กลายเป็นความก้าวหน้า | B |
| ปรับสมดุล: พืชยาวได้โบนัส, ปุ่มปลูกซ้ำ 1 แตะ | คนแวะมาวันละไม่กี่ครั้งได้ผลคุ้ม | C |
| **Deploy สาธารณะ** (GitHub Pages ผ่าน GitHub Actions — ไม่ต้องมี Node ในเครื่อง) + จำกัด API key ตามโดเมน | เพื่อนเล่นบนมือถือได้ด้วยลิงก์เดียว | A |

## Phase 2 — "สัตว์ทุกตัวมีความหมาย" (M–L) ← แก่นที่ผู้ใช้ต้องการ

| งาน | ผลต่อผู้เล่น | เจ้าของ |
|---|---|---|
| ความสามารถพิเศษประจำสายพันธุ์ (~12 แบบใช้ซ้ำ เช่น นกฮูกทำงานกลางคืน +30%, สัตว์น้ำช่วยแปลงข้างบ่อ) | ตัวหายากรู้สึกต่างจริง มีเหตุผลเลือกตัว | B |
| แปลงทีม: พืชต้องการ 2–3 งาน แต่ละช่องใส่น้องคนละตัว ครบทุกงานได้คอมโบ | ต้องสะสมผู้เชี่ยวชาญมาจัดทีม | C + B (task shape) |
| ความผูกพัน ❤️ 0–5: ดูแลบ่อยได้หัวใจ → โบนัสงาน + ของขวัญรายวัน | การดูแลไม่ใช่ภาระ | B |
| PWA ติดตั้งบนมือถือ + เล่นออฟไลน์ + แจ้งเตือนในเครื่อง (พืชพร้อม/น้องหิว) | รู้สึกเหมือนทามาก็อตจิในมือ | A |

## Phase 3 — เนื้อหาลึก + โซเชียล (L, เลือกทำตามความสนใจ)

- **สิ่งปลูกสร้าง**: รังผึ้ง บ่อปลา เหมือง สวนผลไม้ เล้าไก่ คอกวัว — ผลิตของเรื่อยๆ ตามพลังน้องที่ประจำ (C)
- **ครัว/ทำอาหาร**: พืช+ของป่า → อาหารบัฟน้องหลายชั่วโมง (C + B)
- **ผสมพันธุ์**: 2 ตัวโต → ไข่ที่สืบทอดนิสัย/ความสามารถ/โอกาส shiny (B — ต้องเปลี่ยนสัญญาตู้ฟัก)
- **อีเวนต์ประจำสัปดาห์**: ถิ่นอาศัยเด่นประจำสัปดาห์ ไข่จำกัดเวลา (B)
- **โซเชียล**: โปรไฟล์สาธารณะ, เยี่ยมฟาร์มเพื่อน (ดูอย่างเดียว), ลีดเดอร์บอร์ดแบบเล่นๆ (A)
- **ต้องใช้แผน Blaze (มีค่าใช้จ่ายตามการใช้)**: push notification ตอนปิดแอป, ตรวจกันโกงฝั่ง server, แลกของ/ตลาดระหว่างผู้เล่น

## กติกาคุณภาพ v2

1. เปลี่ยนโครง state = ต้องมี migration step + save ตัวอย่างใหม่
2. ทุก release: `tests.html` ผ่าน + ตัวจำลองเศรษฐกิจผ่าน + เช็คลิสต์มือ (360px, dark mode, guest→login→logout→login, รีโหลดตอนออฟไลน์)
3. Flow ทีมเดิม: coder → Reviewer → หัวหน้าทดสอบจริง
4. ฟีเจอร์ที่ตัวเลขอยู่หลายไฟล์ ต้องผ่านตัวจำลองเศรษฐกิจก่อนส่งรีวิว
