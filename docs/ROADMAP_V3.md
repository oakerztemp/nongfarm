# ฟาร์มน้องๆ — Roadmap v3 (ร่างเสนอ, 2026-10-24)

> โจทย์ผู้ใช้: **เล่นแล้วรู้สึกน่ารัก อยากใช้เวลากับเกม อยากเลี้ยงน้อง** — ยังไม่อนุมัติ

## สิ่งที่ยังค้าง (จากรอบก่อนๆ)

| งาน | สถานะ |
|---|---|
| โมเดล 3D ถิ่นอื่น (~85 ตัวยังเป็นอีโมจิลอย) | ยังไม่เริ่ม — ส่งผลต่อ "ความน่ารัก" มากที่สุด |
| แท็บไร่แบบ 3D | ยังไม่เริ่ม |
| Phase 3 เดิม: สิ่งปลูกสร้าง, ทำอาหาร, ผสมพันธุ์, อีเวนต์, เยี่ยมฟาร์มเพื่อน | ยังไม่เริ่ม |
| เล็กๆ: เรียงน้องในตัวเลือกตามพลัง, ป้ายชื่อทับกันในหน้า gallery (QA) | ค้าง |
| ยังไม่ได้ตรวจด้วยตา: ท่าพิเศษวาฬ/อินทรี/ด้วง, ข้อความยืนยันตอนปล่อยน้องที่ประจำแปลง, การแปลงเซฟคลาวด์จริงเป็น v4 | ค้างตรวจ |

## คอมเมนต์ผู้ใช้ → สาเหตุ → ทางแก้

| # | คอมเมนต์ | สาเหตุในโค้ด | ทางแก้ที่เสนอ |
|---|---|---|---|
| 1 | ลานมีของเพิ่มแต่ขนาดเท่าเดิม | กล้องซูมออกให้พอดีลานทุกครั้ง (`fitDistance` ตาม island) → บนจอเท่าเดิม น้องแค่ตัวเล็กลง | **กล้องระยะคงที่** น้องตัวเท่าเดิมทุกระดับ; ลาน S เป็นแปลงเล็กกลางทุ่งกว้าง (หญ้าสูง ชายป่า ลำธารนอกรั้ว) อัปเกรดแล้ว **รั้วขยายกินพื้นที่ป่าจริงๆ**; ลาน XL ใหญ่กว่าจอ → ลากเลื่อนดูได้ |
| 2 | อัปเกรดลานใช้แค่เงิน แล้วสำรวจมีไว้ทำไม | `upgradeBarn` ใช้เหรียญอย่างเดียว; ไม้ 🪵/หิน 🪨 จากการสำรวจขายได้แค่ 3–4🪙 | **ขยายลาน = เหรียญ + วัสดุจากการสำรวจ** (ไม้ หิน แล้วระดับสูงต้องเปลือกหอย/ขนนก/อัญมณีตามของที่เพิ่มในลาน) + **ของตกแต่งลานสร้างจากวัสดุ** (ที่นอน ชามอาหาร ลูกบอล ชิงช้า) ที่น้องใช้งานจริง → การสำรวจมีเป้าหมาย |
| 3 | ปุ่มรับของขวัญใหญ่เกิน ความเด่นต้องอยู่ที่น้อง | การ์ดเต็มความกว้างเหนือฉาก 3D | ลบการ์ด → **น้องถือของขวัญ 🎁 ไว้เหนือหัว แตะน้องเพื่อรับ** (น้องกระโดดดีใจ ยื่นของให้) + ชิปเล็ก "🎁 5" มุมจอไว้กดรับทีเดียว; แจ้งเตือนเต็ม 6 ชม. ด้วยน้องโบกมือ ไม่ใช่แถบ UI |
| 4 | ลานเต็ม ฟักไม่ได้ ต้องไล่น้องออกทั้งที่ไม่รู้ว่าไข่เป็นตัวอะไร | `hatchReady` ปฏิเสธเมื่อ `pets.length >= barnCapacity` | **เปลอนุบาล 👶 (2–3 ช่อง)**: ลานเต็มก็ฟักได้ ลูกน้องรอในเปลจนกว่าจะมีที่ เห็นสายพันธุ์/นิสัย/ไชนี่ก่อนตัดสินใจ; **"ส่งไปบ้านใหม่"** แทนคำว่าปล่อย (ได้ผงดาวเล็กน้อย + น้องส่งโปสการ์ดกลับมาเล่าชีวิตใหม่); ตอนเลือก มี **ตัวช่วยเปรียบเทียบ**: ตัวซ้ำในสมุด, พลัง, หัวใจ, ไชนี่, ประจำแปลงอยู่ไหม |

## Phase 3A — "ลานของน้อง" (แก้ 4 ข้อ, ทำก่อน, ขนาด M)

1. กล้องคงที่ + ทุ่งกว้างนอกรั้ว + รั้วขยายกินป่า + ลากเลื่อนดูลานใหญ่
2. ขยายลานใช้วัสดุ + ร้านตกแต่งลาน (สร้างจากวัสดุ วางในลานได้ น้องใช้จริง)
3. ของขวัญอยู่บนตัวน้อง แตะรับ; ชิปเล็กแทนการ์ด
4. เปลอนุบาล + ส่งไปบ้านใหม่ + ตัวช่วยเปรียบเทียบ
5. ค้างเล็ก: เรียงน้องตามพลังในตัวเลือก

**เกณฑ์เศรษฐกิจใหม่:** เวลาถึงลาน XL ยังอยู่ในกรอบเดิม (±20%), วัสดุไม่กลายเป็นลูปซื้อ-ขายกำไร, ส่งไปบ้านใหม่ได้ผงดาว < มูลค่าไข่ (กันฟัก-ส่งต่อปั๊มผงดาว), ราคาของตกแต่งเป็นที่ใช้เหรียญปลายเกม (ช่วยปัญหาเงินล้น)

## Phase 3B — "จับต้องน้องได้" (หัวใจของโจทย์, ขนาด M–L)

| ไอเดีย | ทำไมน่ารัก/อยากอยู่นาน |
|---|---|
| **ลูบหัว/เกาคาง** (ลากนิ้วบนตัวน้อง) น้องเอียงหัว หลับตาพริ้ม หัวใจลอย; **ลากอาหารไปป้อน** | สัมผัสตรงแทนกดปุ่ม — แก่นของทามาก็อตจิ |
| **ทักทายตอนเปิดเกม**: น้องวิ่งมาหน้ากล้อง โบกมือ บอกเรื่องที่เกิดตอนเราไม่อยู่ | อยากกลับมาเปิด |
| **ของเล่นในลาน**: ลูกบอลที่น้องเตะกัน, ที่นอนที่น้องแย่งกันนอน | มีอะไรให้ดูเพลินๆ |
| **เพื่อนซี้**: น้องบางคู่ชอบกัน เดินด้วยกัน นอนกอดกัน (โบนัสเล็กเมื่อทำแปลงเดียวกัน) | เรื่องราวเกิดเอง |
| **ชุด/เครื่องประดับ**: หมวก ผ้าพันคอ โบว์ (ร้าน + ของจากการสำรวจ) | แต่งตัวน้อง = เหตุผลใช้เงินปลายเกม |
| **โหมดถ่ายรูป 📸 + สมุดภาพ** + สติกเกอร์ | เก็บความทรงจำ แชร์ได้ |
| **บันทึกน้องรายวัน**: ประโยคน่ารักอัตโนมัติ ("วันนี้ปุยเมฆแอบงีบในแปลง #2") | น้องมีชีวิตตอนเราไม่อยู่ |
| **อากาศและกลางวัน/กลางคืน**: ฝนตก น้องกระโดดแอ่งน้ำ; กลางคืนเข้าโรงนอน | โลกมีชีวิต |
| **วันเกิดน้อง** (นับจากวันฟัก): เค้ก ปาร์ตี้ในลาน | ผูกพันระยะยาว |

## Phase 3C — "น้องทุกตัวเป็นตัวจริง" (ทำเป็นคลื่น, ขนาด L)

ปั้นโมเดล 3D ถิ่นอื่นทีละถิ่น เริ่มจากตัวที่ผู้เล่นได้บ่อย (common/uncommon): ป่า → น้ำ → ฟ้า → แมลง → สะวันนา → ขั้วโลก (ถิ่นละ ~12–15 ตัว, ใช้ชุดชิ้นส่วนเดิม)

## Phase 3D — เนื้อหาลึก + โซเชียล (เลือกทีหลัง)

ผสมพันธุ์ (ลูกได้สี/นิสัยจากพ่อแม่), ทำอาหารป้อนน้อง, อีเวนต์ถิ่นประจำสัปดาห์, เยี่ยมฟาร์มเพื่อน, แท็บไร่ 3D

## ลำดับที่เสนอ

3A → 3B (แบ่ง 2 รอบ: สัมผัส+ทักทาย+ของเล่น ก่อน, แล้วชุด/ถ่ายรูป/บันทึก) → 3C เป็นคลื่นคู่ขนาน → 3D
